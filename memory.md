| **LLM resilience:** cache by input hash (`llm_cache`), 429 → exponential backoff + full jitter (max `LLM_MAX_RETRIES`), then fallback provider, then degrade with "Explanation unavailable" | Free quotas are small and models rotate; deterministic checks (axe, keyboard, contrast, heuristics) must never depend on the LLM.
